## 📝 基础概念题

### 1️⃣ 数据类型相关

**Q1: `int`、`long`、`long long` 的大小是多少？为什么它们的大小不是固定的？**

🎓 **费曼教授的简单解释**:
"这就像不同国家的尺子，有的用厘米，有的用英寸。C语言标准只规定了最小要求，具体大小取决于编译器和计算机架构。就像汽车可以是2门、4门或更多门，只要符合基本要求就行！"

💡 **标准答案**:
- C标准只规定了最小大小：`short >= 16位`, `int >= 16位`, `long >= 32位`, `long long >= 64位`
- 实际大小取决于编译器和目标平台
- 常见情况：32位系统上 `int` 是4字节，64位系统上 `long` 可能是4或8字节
- 可以用 `sizeof` 运算符查看具体大小

---

**Q2: `float` 和 `double` 有什么区别？什么时候应该使用哪个？**

🎓 **费曼教授的简单解释**:
"`float` 就像普通尺子，精确到毫米；`double` 就像高精度游标卡尺，精确到微米。日常测量用尺子就够了，但精密实验需要游标卡尺！"

💡 **标准答案**:
- **精度不同**: `float` 约6-7位有效数字，`double` 约15-16位有效数字
- **内存占用**: `float` 通常4字节，`double` 通常8字节
- **性能**: `float` 计算更快，占用内存更少
- **选择原则**: 需要高精度时用 `double`，内存敏感或性能要求高时用 `float`

---

**Q3: 什么是字符常量和字符串常量？它们有什么区别？**

🎓 **费曼教授的简单解释**:
"字符常量就像单个字母积木，字符串常量就像一串字母组成的单词。单个字母用单引号，单词用双引号！"

💡 **标准答案**:
- **字符常量**: 用单引号括起来的单个字符，如 `'A'`、`'1'`、`'\n'`
- **字符串常量**: 用双引号括起来的字符序列，如 `"Hello"`、`"A"`
- **存储方式**: 字符常量存储为单个字符的ASCII值，字符串以空字符 `'\0'` 结尾
- **类型**: 字符常量是 `int` 类型，字符串常量是字符数组类型

---

### 2️⃣ 运算符相关

**Q4: 什么是运算符优先级？为什么 `2 + 3 * 4` 的结果是14而不是20？**

🎓 **费曼教授的简单解释**:
"运算符优先级就像数学中的运算顺序！就像先乘除后加减一样。C语言也有自己的'数学规则'，`*` 和 `/` 比 `+` 和 `-` 更'强势'！"

💡 **标准答案**:
- 运算符优先级决定了表达式中运算的执行顺序
- 乘除法优先级高于加减法，所以 `2 + 3 * 4` 等于 `2 + (3 * 4)` = 14
- 可以用括号改变运算顺序：`(2 + 3) * 4` = 20
- 优先级表：`()` > `++ --` > `* / %` > `+ -` > `关系运算符` > `逻辑运算符` > `赋值运算符`

---

**Q5: `==` 和 `=` 有什么区别？为什么 `if (x = 5)` 是错误的？**

🎓 **费曼教授的简单解释**:
"`=` 就像给变量起名字（赋值），`==` 就像比较两个人是否相同（判断相等）。把赋值当成比较，就像问'这个苹果等于苹果吗？'时，顺手把苹果给了别人！"

💡 **标准答案**:
- `=` 是赋值运算符，将右边的值赋给左边的变量
- `==` 是相等比较运算符，判断两边的值是否相等
- `if (x = 5)` 会将5赋值给x，然后判断x是否为0（非0为真）
- 这样会导致逻辑错误，应该使用 `if (x == 5)`

---

**Q6: `&&` 和 `||` 有什么特点？什么是短路求值？**

🎓 **费曼教授的简单解释**:
"`&&` 就像'并且'，两件事都必须为真；`||` 就像'或者'，至少一件事为真就行。短路求值就像看电影时，如果看到一半就知道结局不好，就直接关掉不看！"

💡 **标准答案**:
- `&&` (逻辑与): 两边都为真时结果为真，否则为假
- `||` (逻辑或): 只要有一边为真结果就为真，两边都为假时才为假
- **短路求值**:
  - `expr1 && expr2`: 如果 `expr1` 为假，就不计算 `expr2`
  - `expr1 || expr2`: 如果 `expr1` 为真，就不计算 `expr2`
- 这提高了效率，也常用于条件判断

### 3️⃣ 类型转换相关

**Q7: 什么是隐式类型转换？什么时候会发生？**

🎓 **费曼教授的简单解释**:
"隐式类型转换就像自动翻译官！当你需要把苹果和橘子一起数时，翻译官会自动把它们都转换成'水果'来计算。C语言的编译器就是这样帮我们处理不同类型的数据！"

💡 **标准答案**:
- 隐式类型转换是编译器自动进行的类型转换，不需要程序员显式指定
- 常见情况：
  - 赋值时：`double d = 5;` (int 自动转换为 double)
  - 运算时：`5 / 2.0` (5 从 int 转换为 double)
  - 函数参数传递时
  - 函数返回值时
- 转换规则：小类型向大类型转换，有符号向无符号转换

---

**Q8: `(double)5 / 2` 和 `(double)(5 / 2)` 有什么区别？**

🎓 **费曼教授的简单解释**:
"第一个就像先把5变成高精度仪器，然后去测量；第二个就像用普通尺子测量完，再声称结果是高精度的。显然第一个更准确！"

💡 **标准答案**:
- `(double)5 / 2`: 5先转换为double(5.0)，然后进行浮点除法，结果是2.5
- `(double)(5 / 2)`: 先进行整数除法(5/2=2)，然后将结果2转换为double(2.0)
- 结果完全不同：前者是2.5，后者是2.0
- 这说明了强制转换和运算符优先级的重要性

---

### 4️⃣ 位运算相关

**Q9: 什么是位运算？主要用在哪些场景？**

🎓 **费曼教授的简单解释**:
"位运算就像在操作微型开关电路板！每个开关只能是开(1)或关(0)。位运算直接操作这些开关，比普通运算更快，特别适合底层编程和性能优化！"

💡 **标准答案**:
- 位运算直接对整数的二进制位进行操作
- 主要运算符：`&`(与)、`|`(或)、`^`(异或)、`~`(取反)、`<<`(左移)、`>>`(右移)
- 应用场景：
  - 设置、清除、切换特定位
  - 快速乘除法（左移相当于乘2，右移相当于除2）
  - 加密算法
  - 图形处理
  - 底层硬件操作
  - 性能优化

---

**Q10: 如何用位运算判断一个数是否是2的幂？**

🎓 **费曼教授的简单解释**:
"2的幂在二进制中只有一个1，就像独生子！用 `n & (n-1)` 就能检查这个'独生子'是否真的只有一个。如果是，结果就是0！"

💡 **标准答案**:
```c
int is_power_of_2(unsigned int n) {
    return n != 0 && (n & (n - 1)) == 0;
}
```
- 原理：2的幂的二进制表示中只有一位是1
- `n & (n-1)` 会清除最低位的1
- 如果结果是0，说明n只有一位1，即是2的幂
- 例外情况：0不是2的幂

## 🚀 进阶思考题

### Q11: 以下代码的输出是什么？为什么？

```c
#include <stdio.h>
int main() {
    int x = -1;
    unsigned int y = 1;
    if (x > y) {
        printf("x > y\n");
    } else {
        printf("x <= y\n");
    }
    return 0;
}
```

🎓 **费曼教授的提示**:
"小心有符号和无符号的比较！这就像比较'欠债1元'和'拥有1元'，计算机可能会理解错！"

💡 **思路提示**:
- 有符号整数会被转换为无符号整数进行比较
- -1转换为无符号整数后会变成一个很大的正数
- 结果可能出乎意料

## 💡 面试技巧

### 🎯 如何回答技术问题

1. **先用简单比喻解释** (费曼学习法)
2. **然后给出技术性答案**
3. **提供代码示例**
4. **说明应用场景**
5. **指出常见陷阱**

### 📝 回答示例模板

```
🎓 简单解释: [用生活中的比喻]
💡 技术答案: [准确的技术描述]
🎯 代码示例: [具体代码]
⚠️ 注意事项: [常见陷阱和最佳实践]
🚀 应用场景: [实际使用情况]
```

### ⚠️ 常见误区

1. **混淆运算符**: `=` 和 `==`, `&` 和 `&&`
2. **忽略优先级**: 忘记括号的重要性
3. **类型转换错误**: 不理解隐式转换规则
4. **整数溢出**: 忽略数值范围限制
5. **有符号无符号混用**: 导致意外的比较结果
