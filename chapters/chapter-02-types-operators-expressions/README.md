## 💡 费曼教授的重点提醒

### 🔑 关键概念
"记住这些核心概念，它们是C语言的基石！"

1. **数据类型大小不固定**
   ```c
   sizeof(int)  // 可能是2或4字节
   sizeof(float) // 通常是4字节
   sizeof(double) // 通常是8字节
   ```

2. **整数除法截断**
   ```c
   5 / 2    // 结果是2，不是2.5！
   5.0 / 2  // 结果是2.5
   ```

3. **运算符优先级很重要**
   ```c
   int result = 2 + 3 * 4;  // 是14，不是20！
   ```

### ⚠️ 常见陷阱
"小心这些'坑'，很多初学者都会掉进去！"

1. **混淆 == 和 =**
   ```c
   if (x = 5)  // 错误！这是赋值不是比较
   if (x == 5) // 正确的比较
   ```

2. **整数溢出**
   ```c
   int big = 20000 * 20000;  // 溢出了！结果不对
   ```

3. **符号扩展**
   ```c
   char c = 0xFF;  // 可能是-1而不是255
   ```
